# MyArchive 产品说明

MyArchive 是一款面向高中生及成长记录场景的个人经历记忆库。它把零散的活动、想法、照片和材料整理成可检索、可回顾的长期档案，并通过 AI 辅助生成事实型摘要、检索经历和准备文书素材。

- 在线地址：<https://www.my-archive.top/>
- 使用方式：浏览器直接访问，无需注册或登录
- 适用设备：桌面端与移动端浏览器，桌面端拥有更完整的图谱和多栏体验

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 经历记录 | 通过文字、语音、文档或照片保存活动；标题、分类和摘要可由 AI 辅助生成 |
| 我的记录 | 按关键词和分类搜索经历，打开详情后可修改标题、日期、分类和原始描述 |
| AI 对话 | 普通对话、经历检索、追问指定事件、通过多轮对话创建记录，并可生成 Word 或 PDF 文档 |
| 随手记 | 在首页快速保存尚未形成完整故事的念头，并在随手记时间线中回看 |
| 日历视图 | 按日期汇总事件和随手记，查看个人经历轨迹 |
| 成长画像 | 根据经历原文与附件数量计算特质雷达、年度领域变化及可追溯证据 |
| 事件星球 | 以可拖拽的 3D 关系图展示经历之间的时间、分类和关键词关联 |

## 推荐使用流程

1. 在首页点击“开始记录”，先写下发生了什么。标题和分类可以暂时留空。
2. 核对活动日期，按需添加 PDF、DOC、DOCX 或照片，再保存记录。
3. 在“我的记录”中搜索并打开详情，补充原始描述或附件。
4. 使用“AI 对话”按申请文书、简历、面试等场景检索经历，并追问具体事件。
5. 定期查看“成长画像”“事件星球”和“日历”，发现长期变化和材料缺口。

## 重要数据说明

当前在线版是无登录的共享演示环境。经历记录、随手记和自定义分类使用同一套共享云端数据，不区分访问者；其他访问者可能看到、修改或删除这些内容。请勿填写真实姓名、联系方式、证件信息、账号密码、健康信息、未公开申请材料等敏感内容。

附件在当前在线部署中不属于云端主存储，通常只保留在当前浏览器的本地附件缓存中，不能保证跨设备或跨浏览器读取。聊天记录保存在当前标签页的会话存储中，关闭标签页后可能消失。

## 当前限制

- 在线设置页会返回首页，AI 能力取决于部署端是否已配置模型；模型不可用时会切换为本地演示分析。
- 语音转文字需要浏览器麦克风权限和可用的语音模型配置，单次录音最长 10 分钟。
- 当前文档上传会保存文件并把文件名作为检索线索，不会解析 PDF、DOC 或 DOCX 的正文。
- 删除整条经历后无法恢复；执行删除前应再次确认记录和附件是否仍需保留。
- 当前产品适合演示和个人开发验证，不适合作为多人公开生产系统。
